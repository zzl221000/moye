# PDF 导出的唯一权威是 dompdf

墨页的版式预览按页卡呈现，但分页仍只由 dompdf 决定。预览调用 dompdf 的 `collectSnapshotData()`，读取它实测出的节点几何、行盒、页眉/页脚高度与分页指令，再按同一内容高度切片；预览本身不做断行或断页计算。写作面仍不做分页所见即所得：一旦写作面自己算页边界，就会出现两套分页结果，而预览无法证明导出结果。

快照 API 不可用或抛错时，预览退回连续纸张，页数恢复为 `≈` 估算；导出行为不受影响。

## Considered Options

- QuireKit 的分页渲染器加其 PDF 导出：导出权威会分裂成两套，且 PDF 导出是商业组件，不采用。
- 写作面自行分页、预览跟随：需要复刻 dompdf 的断行与断页规则，维护成本高于收益。
- 用 `computePageBreaks` 给预览画页边界：它只是粗略的内容高度倍数，不按行盒与 `divisionDisable`/`pageBreak` 分配，页数会与导出漂移。
- 预览连续渲染：放弃页卡，用户无法在导出前确认真实页边界。
